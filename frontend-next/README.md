# frontend-next

Modern Next.js dashboard frontend for MiroFish AR Fintech Simulator.

## Run locally

```bash
cd frontend-next
cp .env.example .env.local
npm install
npm run dev
```

Default URL: `http://localhost:3000`

Set API base URL in `.env.local`:

```env
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
```
